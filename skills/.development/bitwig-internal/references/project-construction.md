# Disposable fixture construction only

General project/import/lifecycle orchestration is retired. Supporting native
New/Open/Save, focus and folder/clip creation actions use the directly routed
[keyboard workflow](../../../bitwig-explore/references/keyboard-workflow.md),
with actual profile/focus/input/readback qualification through Use Computer.
No screenshot-based systematic procedure or helper CLI is allowed.

The development harness retains one `construction native` experiment: create two
named native note clips plus direct CC automation in an explicitly disposable
project. It requires current harness UUID/revision and refuses an existing fixture;
never replay to repair an unknown result. It is not a production import route.
`probe authority` returns only its minimal native document authority.

Core native note/automation writes use the existing EditorAdapter61 and
AutomationAdapter61 transaction. Instrument61 inserts only Instrument Layer or
exact installed Kontakt, and configures native Layers. No generic device, parameter,
remote page, mixer, render or plugin-state framework is authorized. Library preprocessing
and external NKI loading retain their own narrow contracts.

Private method history in SOURCES.md is evidence for its original build/fixture,
not authorization to restore retired helpers. New native behavior needs a concrete
core requirement, primary-source trace and an ephemeral independent readback probe.

# Kontakt setup design rationale and evidence

Authoring-only rationale. Runtime readiness and assignment are owned by
[SKILL.md](SKILL.md), [eligibility](references/eligibility.md) and
[assignment](references/assignment.md).

One integrated assignment was chosen so native receiver identity, editor ownership
and external NKI loading stay associated with one retained operation. A separate
manual loader would lose that ownership relationship. The loader's narrow role
also separates stock loading from later authorized dashboard configuration.

Earlier qualification stopped at a native/Win32 visibility disagreement before
NKI submission. Later integrated replacement, closure and open-editor handoff
observations are retained in the syllable builder's
[execution findings](../kontakt-syllable-builder/sources/ITERATION.md) and project
receipts. The older failure is not a blanket current inability claim. This file
contains no alternate runtime gates or recovery procedure.

# Intake design rationale and evidence

Authoring-only rationale. [SKILL.md](SKILL.md) owns intake execution and routes
supporting actions to the computer and session action references.

Opaque source preservation was separated from musical interpretation so intake can
establish a workspace without implying that an accepted file format is supported
by the converter. Native saved identity distinguishes a real project from a folder
scaffold. Original byte preservation supports later provenance checks.

Earlier repair work lacked computer access and left New/Open qualification open.
That historical observation is not a runtime capability test. The keyboard
reference contains current action-specific execution conditions and Save evidence.

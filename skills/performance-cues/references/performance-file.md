# Write the project's PERFORMANCE.md

Read before drafting, updating or reconciling a cue sheet. The
[shared PERFORMANCE.md template](../../score-intake/assets/PERFORMANCE.md) owns
the whole-document structure. Merge the example below into its interpretation,
cue map, interpretive decisions and cue placement evidence sections. Preserve
realization/bindings, configuration verification and user commentary. Existing
cue-only files may be extended without discarding their decisions. A prose review
does not imply DAW changes.

```markdown
## Interpretation and cue map

[Two to four sentences: character/pulse, the principal trajectory and climax,
the subordinate peaks, and the closing release. Use conventional terminology.]

### Cue map

| Cue key / Bitwig name | Musical function | Performance direction |
| --- | --- | --- |
| PC01 · Opening | Instrumental introduction; imitative descending motif | Maintain the crotchet pulse; carry the motif across barlines, with light accompanying quavers. |
| PC07 · Harmonic climax | Principal harmonic culmination; accented dissonance | Sustain the prepared dissonance in the named voice; balance the moving bass beneath it, then release through its resolution. |

### Interpretive decisions and sources

- **PC07 → PC08:** [Current musical evidence and precise cited source;
  distinguish the source's analysis from the chosen editorial shaping.]
- **PC12:** [Any consequential edition/ending/agogic decision and its authority.]

### Cue placement evidence

Project: [native name/UUID, rendition/edition, observed date].
Notes: [capture link and actual part/clip scope; important gaps].
Markers: [verified / proposed / partially applied / stale; readback artifact].
Optional location aids: [only useful sparse bar references, with numbering edition].
Sources: [short bibliographic entries with page/example/section and direct links].
Open questions: [only uncertainties that affect performance; omit if none].
```

Replace the illustrative rows with this piece's own cues. Never imply that PC07
must always mean the climax. The map is the performer's main view: short enough
to consult during rehearsal, with concise actionable directions for entries,
phrasing, balance, articulation, intensification and release. Expand only the
musically consequential decisions below it. Prefer cue-key intervals such as
`PC07 → PC08` to repeated bar ranges; do not put bar numbers in headings or keys.
Use a bar reference only when it helps find a score detail or compare an edition.

Cue key and native marker name must match one-to-one; include the exact current
name so a performer can find it. Keep the keys when sections move. If a function
disappears, mark its key retired rather than silently reassigning it to another
event. New cues take unused keys; numbering need not remain chronological.

Before delivery, read the file as a performer: can the player understand the
global arc, hear which part leads at each cue, prepare the next entry and know
when to release? Delete analysis that does not inform an action. Check citations
against the actual passages and separate verified host placement from proposals.

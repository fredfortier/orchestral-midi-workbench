# Sources and authoring decisions

The 2026-11-23 expressive-design revision generalizes the reasoning from a
score-based orchestral expression proposal. The existing production skills own
their respective stages. The proposal supplied the motivating failure modes,
including an inaudible control, a shallow dynamic hierarchy and ambiguous
foreground directions. Its cue locations, settings and orchestration remain
project decisions.

## Boundaries tested in author review

- A researched proposal for an active arrangement returns an event, role, action
  and audible criterion. Receiver-specific advice can use Realization's
  interpretation reference without running its conversion or import stages.
- A credible source and a correctly stored CC curve can coexist with an
  unresponsive patch or a masked contrapuntal entry. Capability evidence,
  native readback and in-context listening answer different questions.
- A score-based plan can use the literature before native MIDI exists. Actual
  marker work still requires the current arrangement and readback. A routine
  marker placement from an agreed cue sheet retains its existing route.
- An authorized live edit uses Bitwig Edit. A generated rendition uses Score
  Realization. Neither route depends on a new worksheet or approval stage.

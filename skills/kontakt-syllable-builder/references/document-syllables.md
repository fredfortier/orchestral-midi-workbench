# Document an eligible patch

Input: initialized library root, actual NKI inventory and applicable publisher
manual. Output: merged INSTRUMENT.md patch facts; return to instrument-intake.
This documentation pass neither loads patches nor programs a performance.

1. Identify exact relative NKIs exposing an editable syllable dashboard. Separate
   full builders, restricted solo builders, automatic Performance cycles and
   fixed-vowel instruments. A product-wide feature claim does not qualify every NKI.
2. Read the matching manual pages and their UI images. Extract the complete menu
   visually when labels are absent from PDF text. Preserve order, spelling and
   case. Record missing/uncertain labels rather than filling from another library.
3. Add the following conditional section to INSTRUMENT.md:

   | Exact relative NKI(s) | Builder family / section | Ordered sample labels | Sustain/staccato availability | Evidence |
   | --- | --- | --- | --- | --- |

   | Exact patch scope | Word/cell capacity | Advance / wrap / reset | Numeric selectors and HLS assignments | Entry/release and persistence limits | Evidence |
   | --- | --- | --- | --- | --- | --- |

4. Describe Connect/Morph, loop, automatic pause reset, attack/offset controls,
   dynamics/velocity roles and relevant defaults separately from current settings.
   Record numeric MIDI keys with the displayed octave label; an octave name alone
   is not a numeric mapping. Unpublished capacity/thresholds remain unknown until
   a separately authorized observation establishes them.
5. Attribute every shared rule and exception to manual edition/page/section or
   exact-patch observation. Sample labels are not IPA; document pronunciation only
   from identified listening or vendor evidence. Distinguish recorded vowels from
   attacks/consonants and state known diction limits.
6. Group entries only where identical behavior is evidenced and every NKI remains
   identifiable. Preserve initialization receipts and older empirical findings.
   Report documentation eligibility separately from live-control qualification.

Refresh only missing or changed facts. Do not copy a project's lyric choices,
channel assignments or preferred substitutions into the library catalogue.

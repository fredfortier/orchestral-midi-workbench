# Mixing skill design rationale

Authoring-only rationale. Runtime execution is owned by [SKILL.md](SKILL.md) and
its directly routed [technique reference](references/mixing-techniques.md).

The reference-backed shape separates conditional musical/measurement knowledge
from the host-operation sequence. Native observations and renders were retained
as different evidence because stored settings cannot establish audible balance.
The source-backed technique material includes contextual masking and quantitative
diagnostics without a universal numerical masking threshold. This distinction
motivated the runtime separation between measurement and listening claims.

[SOURCES.md](SOURCES.md) retains source lineage, rejected approaches and author
walkthroughs. Moving the former runtime content out of this file preserves those
techniques and citations without making a skill specification executable.

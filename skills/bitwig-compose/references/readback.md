# Read back the current arrangement

Start with the intended native project and exact track/group or passage. For a
question answered by the stored clip notes, pass those exact paths to
[exploration](../../bitwig-explore/SKILL.md) and give the complete current read
to [score analysis](../../score-analysis/SKILL.md) with the musical question.

For a fresh reconstructed score, give the exact project or group to
[MIDI2 export](../../bitwig-export-midi2/SKILL.md). Require a fresh successful
capture of that scope before assembling and reconstructing. Give the resulting
current score and declared interpretation losses to score analysis. A failed
capture leaves the matching scope unresolved. Report capture, conversion and
editorial analysis times separately when measuring the workflow.
